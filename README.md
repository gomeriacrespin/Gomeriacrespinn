# Gomería Don Crispin — Página web

Landing page responsive lista para GitHub Pages.

## Publicar en GitHub Pages
1. Creá un repositorio nuevo.
2. Subí `index.html`.
3. En Settings → Pages, seleccioná la rama principal y la carpeta `/root`.
4. Guardá y GitHub te dará el enlace público.

Los datos del negocio usados en la demo fueron tomados de información pública encontrada en la web. Antes de entregársela al cliente, conviene confirmar teléfono, horarios y servicios.
